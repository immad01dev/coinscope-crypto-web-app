# CoinScope - Crypto Marketplace 🚀

CoinScope is a modern cryptocurrency marketplace built with React and Vite.  
It allows users to explore real-time cryptocurrency prices, search coins, change currency, and view detailed information about individual cryptocurrencies using the CoinGecko API.

## 🚀 Features

- 📊 Real-time cryptocurrency data
- 🔍 Search cryptocurrencies by name or symbol
- 💱 Currency switching (USD, EUR, INR)
- 📈 View coin prices, market cap, 24H changes
- 🪙 Individual cryptocurrency details page
- ⚡ Fast and responsive UI
- 🌙 Modern crypto marketplace design

## 🛠️ Technologies Used

- React.js
- Vite
- React Router DOM
- Context API
- CSS3
- CoinGecko API
