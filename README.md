# 🚀 CoinScope - Crypto Marketplace

**CoinScope** is a modern cryptocurrency marketplace built with **React.js** and **Vite**.  
It allows users to explore real-time cryptocurrency prices, search cryptocurrencies, switch currencies, and view detailed information about individual coins using the **CoinGecko API**.

## ✨ Features

- 📊 **Real-time cryptocurrency data**
- 🔍 **Search cryptocurrencies by name or symbol**
- 💱 **Currency switching support (USD, EUR, INR)**
- 📈 **View live prices, market cap, and 24H price changes**
- 🪙 **Individual cryptocurrency details page**
- ⚡ **Fast and responsive user interface**
- 🌙 **Modern crypto marketplace design**

---

## 🛠️ Technologies Used

- **React.js**
- **Vite**
- **React Router DOM**
- **Context API**
- **CSS3**
- **CoinGecko API**

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/immad01dev/coinscope-crypto-web-app.git
```

### 2. Navigate to project directory

```bash
cd coinscope-crypto-web-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

The application will run on:

```bash
http://localhost:5173
```

## 🔑 API Configuration

This project uses the **CoinGecko API** to fetch real-time cryptocurrency data.

Create your API key from:

**CoinGecko API:**  
https://www.coingecko.com/en/api

Add your API key inside:

```text
src/context/CoinContext.jsx
```

Example:

```javascript
"x-cg-demo-api-key": "YOUR_API_KEY"
```
